# The Heuristic Project

Public website for a nonprofit teaching Algebra 1 visually.

## Run locally

```bash
cd workspace/heuristic-project
python3 -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173).

## Edit before you launch

- Contact inbox: `hello@theheuristicproject.org` in `app.js` and `join.html`
- Co-founder name on `about.html`
- Any location, donation link, or 501(c)(3) language once you have it

## Deploy

The site is static HTML, CSS, and JS. Drop the folder on [Vercel](https://vercel.com), Netlify, or GitHub Pages.
